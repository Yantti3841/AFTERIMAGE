# 小红书小程序接入工程（web-view）

这是小红书官方 web-view 容器接入源码，不是可直接在网页后台上传的最终小程序发布包，也不是原生 WebGL 重写版。完整的八种效果、媒体输入、票根和导出由已部署的手机 H5 执行。

## 上传步骤

1. 登录 https://miniapp.xiaohongshu.com/ ，按平台要求注册小程序、完成所需资质与备案，取得自己的 AppID。
2. 使用官网提供的开发者工具，以自己的 AppID 创建一个原生小程序项目。保留工具生成的项目配置文件；将本目录 app.js / app.json / app.css / pages 复制到该项目的小程序源码根目录。不要将整个网页 dist 当作原生小程序上传。此包不伪造 AppID 或项目配置。
3. 先将随附的手机网页版部署到你控制的 HTTPS 域名。域名需要公网可访问、无需登录。当前代码中的 chatgpt.site 地址仅作为原项目地址参考，该站目前仍为所有者私有，不能直接供公众访问；请替换 pages/index/index.js 中的 url。
4. 在小红书后台配置这个 H5 的业务域名。按后台要求下载域名校验文件，放到手机网页版网站根目录（源码项目可放 public/ 后重新 build），验证成功后再测试 web-view。URL 参数不能替代域名校验。
5. 在开发者工具检查项目，预览真机。重点验收：照片选择、八种效果、视频解码、摄像头授权、MP4/音频、图片长按保存、系统文件分享。模拟器“页面能打开”不代表真机所有媒体能力可用。
6. 开发者工具上传开发版 → 后台版本管理生成体验版 → 真机测试 → 提审 → 审核通过后发布。小红书不提供把任意 React ZIP 直接变成已发布小程序的入口。

## 功能与适配边界

- 手机 H5 已有触摸控件、720p 默认值、全屏替代布局、图片预览/长按保存、可用时调用系统文件分享。
- 小程序 web-view 对 getUserMedia、MediaRecorder、Canvas captureStream、Web Share 的支持由小红书客户端和操作系统决定，尚未完成小红书真机验证。浏览器缺少录制能力时页面会明确提示，不会伪装成导出成功。原生相册写入和原生录制没有在此工程实现。
- 如果审核类目或 WebView 禁止摄像头/文件下载，需用目标平台允许的原生组件和桥接补齐，不能仅靠容器代码强行开放权限。请勿在未验收前宣传“小红书内全部功能可用”。手机系统浏览器可作为独立入口。
- 用户选择的媒体在本地处理，未接入上传服务器；小程序隐私声明需按实际所用权限填写。
