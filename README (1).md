# AFTERIMAGE · 余像

手机端与小红书接入的本轮发布说明见 [docs/发布与手机使用.md](docs/发布与手机使用.md)。小红书工程在 `xhs-miniapp/`，需要配置自己的 AppID 和公网业务域名；尚未完成小红书真机验收。源码附带 GitHub Pages 工作流，上传后按说明启用即可构建公开网页。

以 After Hours Til Dawn Tour 的现场视觉为灵感制作的实时舞台影像处理器。React + Vite + Three.js WebGL Shader，无后端，摄像头画面和视频文件都在浏览器本地处理。

## 启动

```powershell
pnpm install
pnpm dev
```

打开终端显示的 localhost 地址。生产构建：`pnpm build`；本地检查构建：`pnpm preview`。摄像头需要 localhost 或 HTTPS，首次开启时允许浏览器访问。

## 使用

1. 默认显示空白预览，拖入视频、点击选择视频文件或开启摄像头后开始处理。界面不包含生成的演示素材。
2. 选择摄像头 → 开启摄像头，或上传 MP4、MOV、WebM。摄像头优先请求 1920×1080 / 30 fps，实际输入取决于硬件。再次点击可关闭摄像头。
3. 左侧「视觉效果」切换八种效果，各自保留参数，切换不重新上传、不重置播放位置；摄像头和视频使用同一套效果。恢复默认只重置当前效果。
4. 前后对比显示左原片、右处理；上传视频可暂停、拖动时间轴、监听原声。竖屏或其他比例素材保留比例并加黑边。
5. 开始录制保存摄像头画面。导出完整视频从头以正常播放速度处理，结束后自动下载。提前停止保存已处理部分，可通过下方下载链接再次下载。
6. 音频驱动和麦克风功能已移除，上传视频保留原声并支持监听。
7. 开启「香港站票根」后，可上传 JPG / PNG / WebP 照片，照片使用同一套八种滤镜；支持暂停照片动效、导出 PNG 或录制动态票根。主票、副券与日期选项统一显示英文月份 Oct，页面页脚链接及导出票根署名为「小红书 @Figma男人」，链接由用户提供。八种滤镜画面都可嵌入红黑纪念票根。选择演出日期，填写 Gate、Level、Block、Row、Seat，点击「保存票根 PNG」导出 1760×780 图片；未载入媒体时使用文字图形。载入媒体后，原有视频导出按钮会导出 1080p 或 720p 动态票根并保留视频原声。
8. 香港站日期依据启德体育园官方活动页：2026-10-24、25、30、31。票根为用户自制纪念设计，座位字段由用户按自己的票面填写，不验证真实座位或生成入场凭证。来源：https://www.kaitaksportspark.com.hk/events-tickets/the-weeknd-after-hours-til-dawn-tour

## 八种视觉效果

- **银红重曝**：依据视频 2，将现场调色改为灰黑影调、银白高光、淡红肤色、斜向拖光和真实前帧重曝；长曝光组可独立关闭，不新增烟雾。
- **冷白轮廓**：以 Sobel 梯度和局部高频细节提取人物与环境轮廓，压成黑底冷灰蓝碎线和细节颗粒。可调整线宽、阈值、强度、破碎程度、细节、亮度、冷蓝色调，以及新增的轮廓模糊。
- **红白泛光**：灰白高光、轻微红色染色、斜向高光长影与切片错位；方向长影、角度和真实前帧残影可独立调整。
- **青绿散射**：依据视频 1，收紧暗部、保留白绿高光，添加局部绿青溢色；暗部截止、色散、扩散和短拖影独立可调。
- **电蓝残影**：深蓝底色，抑制平坦亮背景，局部结构高光保留青白色；高光上限控制亮度。方向长影、柔化与真实前帧反馈叠加，移除网格随机偏移和蓝色切片，运动残影连续衰减，不产生人为方块。
- **白色闪光**：依据视频 4，短促亮起并快速衰减，间隔中保留暗部与少量原色，配合竖向拉光和短残影；频率为 0 时停止曝光脉冲。
- **蓝色旋屏**：黑底上的冷蓝立体视频屏，使用射线与旋转长方体求交生成透视，相邻竖向面同步播放原片，保留面间明暗与屏幕横纹。旋转速度可反向或置 0，角度、大小与深度独立控制；每面按原片比例居中裁切。
- **荧光线栅**：依据视频 3 新增效果 8，压低均匀绿线底色，突出粉白轮廓、柔边发光点和少量星芒。光点附着原片亮部与局部细节，各自平滑明灭；闪光亮点、光点大小、闪烁速度、线密度、阈值及粉白比例可调。速度为 0 时保持静态光点，暂停时固定闪烁和残影。
- 除关闭长曝光的银红重曝外，效果使用离屏 GPU 后处理。泛光提取亮部后在四分之一分辨率做水平高斯模糊，再在合成时做垂直高斯模糊；模糊直接处理滤镜输出；拖影使用双缓冲的真实前帧反馈，切换效果、输入源、分辨率、视频定位与对比状态会清除旧反馈。暂停时固定反馈结果，避免暂停画面持续变化。

## 实现

- `src/engine.js`：单个全屏片元 Shader；低曝光、深黑阴影、收敛的高光曲线、低饱和灰黑中间调、暗蓝细节保留、依据原片暖色区域的局部珊瑚红偏移、屏幕柔化、轻量 Bloom、动态颗粒、不均匀 LED 横向纹理、暗角。
- 以用户最新参考图为调色目标，纯黑区域保持黑色，灰色背景不整体染蓝，保留衣物的暗蓝色，肤色与暖色受光区域偏暗珊瑚红。滤镜只处理原片颜色与屏幕纹理，不添加场景覆盖层。输入素材的照明、构图和曝光仍影响结果。
- `src/settings.js`：统一预设和参数描述。
- `src/main.jsx`：输入源生命周期、控件、播放、Web Audio 音轨和 MediaRecorder 导出。
- `src/audio.js`：共享视频原声图、静音监听与导出分支。
- GPU 循环独立于 React，仅约每秒更新一次 FPS；输出支持 1080p 与 720p，目标 30 fps。

## 导出与兼容边界

- 运行时使用 `MediaRecorder.isTypeSupported()` 优先选择 H.264 / AAC MP4，浏览器无法编码 MP4 时回退 WebM。扩展名来自编码器实际 MIME 类型，不会将 WebM 改名成 MP4。
- 上传视频保留原声；监听静音不影响导出音轨。摄像头只请求视频权限，不采集麦克风。
- 文件扩展名不保证解码兼容，尤其 MOV 的 HEVC / ProRes。无法解码时会明确提示并回到空白预览。
- 导出耗时约等于视频时长；页面切到后台会停止并保存已录部分，避免后台 GPU 限速造成长时间冻结。浏览器卡顿仍可能导致丢帧，30 fps 是目标而非逐帧离线编码保证。
- 编码数据保存在内存中直到生成文件，长视频会消耗较多内存；暂未接入磁盘流式写入或离线 FFmpeg。
- 低性能设备建议使用 720p。浏览器需支持 WebGL、Canvas captureStream、MediaRecorder；推荐使用支持这些功能的桌面浏览器。
- 用户媒体不会上传。字体使用 Arial 与本机微软雅黑，不依赖外部字体请求。

## 视觉说明

界面依据最新红黑巡演海报参考重制：黑底、深红选中态、米白文字、全宽 AFTERIMAGE 大字标与细线分区；保留左侧控制、右侧预览。移除效果描述、预设状态文案与音频驱动面板。字标、页面标题和导出文件名统一使用 AFTERIMAGE。

验证：桌面 1536×1024、移动 390×844，滤镜开关、预设重置、分屏、全屏、视频上传和定位、跨模式参数共享、模拟摄像头录制。实测短片导出为 1920×1080 H.264 / AAC MP4，输出重新播放可解码并有音频字节；720p WebM 回退和错误视频恢复已验证。真实摄像头、其他浏览器和超长视频仍需目标设备验证。
